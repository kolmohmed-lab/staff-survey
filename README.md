# Staff Survey

Anonymous monthly wellbeing survey for Academic and Operations teams.

## Stack
- Next.js + TypeScript
- Vercel hosting
- Power Automate server-side submission bridge
- Microsoft Lists / SharePoint storage

## Required environment variable
Create this in Vercel Project Settings → Environment Variables:

`POWER_AUTOMATE_URL`

Set it to the HTTP POST URL generated by the Power Automate flow. Never commit that URL to GitHub.

## Local development
```bash
npm install
npm run dev
```

## Current storage mapping
The proof-of-concept flow sends team, survey month, a temporary wellbeing score placeholder, and a JSON copy of all survey answers in the comment field. The Microsoft List and Power Automate schema should be expanded before production launch so each answer has its own reporting column.
